## 📚 Curriculum Breakdown & Core Answers

### Module 1: Introduction to Gamma & Workspace Fundamentals

#### 1.1: Four Ways to Create
Gamma provides four primary entry points to build decks, documents, and web pages:
1. **Generate from scratch**: Provide a natural language prompt, and Gamma's AI creates an outline, drafts content, selects images, and styles cards.
2. **Paste in text**: Ideal for existing notes, meeting minutes, markdown documents, or executive summaries. Gamma automatically structures raw text into cohesive card blocks.
3. **Import existing files**: Upload PDFs, PowerPoint (`.pptx`), Word documents (`.docx`), or Google Docs. Gamma converts static slides into flexible, responsive cards.
4. **Remix from templates**: Start from professionally designed community and enterprise templates for pitches, sprint reviews, and roadmaps.

#### 1.2: Your Dashboard Hub
- **Organization**: Group decks into shared team folders, personal spaces, and star key presentations as Favorites.
- **Views**: Toggle between Grid View (visual thumbnails) and List View (metadata, last modified, view counts).
- **Themes & Templates Gallery**: Access corporate brand kits, custom fonts, color palettes, and community designs.

#### 1.3: Understanding Cards
- **Fluid Container Model**: Unlike rigid 16:9 PowerPoint slides, Gamma cards expand dynamically to fit their content.
- **Customization**: Style individual cards with accent backgrounds, visual containers, card splitters, and custom column layouts.

### Module 2: AI-Powered Creation & Smart Design

#### 2.1: Advanced Mode & AI Controls
- **Advanced Mode**: Fine-tune card density, target audience tone (Executive, Technical, Creative), image style (Photorealistic, Editorial, Minimal 3D), and language before generation.
- **Image Generation Controls**: Specify aspect ratios, artistic themes, and upload reference imagery for brand consistency.

#### 2.2: Meet Agent (Your AI Design Partner)
- **Conversational Editing**: Highlight any card or element and instruct Agent to "make this punchier", "summarize in 3 bullets", or "convert this text into a 3-column comparison".
- **Web Research & Citations**: Agent can query live web sources and insert verified data points with direct source footnotes.
- **Screenshot Ingestion**: Paste a UI screenshot or chart; Agent extracts the information and reconstructs it natively as editable text and cards.

#### 2.3: Smart Layouts
- **Pre-Built Visual Structures**: Insert pre-formatted Smart Layouts for Timelines, Before/After comparisons, Process flows, Metric highlights, and Multi-column grids without manual drag-and-drop alignment.
- **One-Click Theme Switching**: Change the entire deck's theme (colors, fonts, card borders) instantly without breaking content layouts.

#### 2.4: Content that Shines
- **Slash Commands (`/`)**: Type `/` inside any card to insert columns, callout boxes, toggle accordions, charts, and mathematical equations.
- **Rich Media Embeds**: Embed live interactive widgets, Figma prototypes, YouTube videos, Loom walkthroughs, and Airtable bases directly inside cards.

### Module 3: Presenting, Collaborating & Publishing

#### 3.1: Present with Confidence
- **Presenter View**: Separate presenter window with live timer, upcoming cards, and private speaker notes.
- **Spotlight Mode**: Dim previous content and illuminate only the active bullet or section as you speak to maintain audience focus.
- **Follow Links**: Allow remote attendees to follow along with the presenter's navigation in real time.

#### 3.2: Collaboration & Enterprise Analytics
- **Granular Permissions**: Set access levels (Viewer, Commenter, Editor, Workspace Admin).
- **Password Protection**: Send secure external links with optional password protection and expiration dates.
- **Engagement Analytics (Pro)**: Track slide-by-slide completion rates, total unique viewers, dwell time per card, and export interaction logs.

#### 3.3: Export & Multi-Channel Distribution
- **PDF Export**: Generates high-resolution vector PDF documents suitable for board printing.
- **PowerPoint Export (`.pptx`)**: Generates fully editable PowerPoint files with native shapes and text boxes.
- **Direct LinkedIn Sharing**: Connects via LinkedIn Connected Apps to share decks directly to your feed.
- **Live Web Page Publishing**: Publish any deck as a public or custom-domain website with automatic instant updates.

### Module 4: Productivity & Best Practices

#### 4.1: Work Smarter & Credit Efficiency
- **Keyboard Shortcuts**:
  - `Cmd/Ctrl + Enter`: Add a new card.
  - `Cmd/Ctrl + K`: Open quick action command palette.
  - `/`: Trigger component insert menu.
- **Credit Management**: Iterating via text edits and Smart Layout adjustments does not consume AI generation credits; reserve prompt generation for new drafts and complex remixes.
